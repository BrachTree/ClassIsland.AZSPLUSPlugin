// 文本轮播示例文件
// 每行为一个句子或一组句子，// 开头的行为注释
//
// 参数使用 <> 包裹：
//   <5>       显示时长5秒
//   <#FF0000>  红色
//   <50>      滚动速度50px/秒（长文本专用）
//   <true>    是否滚动完暂停（true=暂停，false=循环）
//   <true>    是否禁用过渡动画（true=禁用，false=跟随组件设置）
// 颜色也可附着在句子末尾：句子<#FF0000>
// 组内句子以空格分隔，若句子需要包含空格，用下划线 _ 连接

// === 单句格式：句子 <显示时长> <颜色> <滚动速度> <是否滚动完暂停> ===
你好世界 <5> <#FF0000>
今天天气不错 <3>
欢迎来到ClassIsland

// === 长文本滚动（超过350px自动水平滚动）===
这是一段很长的文本内容用于测试水平滚动效果功能是否正常工作请仔细观察 <10> <#00FF00> <50> <true>
另一段超长文本用于测试循环滚动模式当文本超出容器宽度时会自动开始水平滚动 <8> <50> <false>

// === 组格式：[句子1<颜色> 句子2 句子3 <每句时长> <是否禁用过渡动画> <滚动速度> <是否滚动完暂停>] ===
[第一句<#FF0000> 第二句 第三句 <3> <true>]
[早上好 下午好 晚上好 <2> <false>]

// === 含空格的句子用下划线连接 ===
[Hello_World 你好_世界 测试成功 <3>]

// === 混合格式 ===
温馨提示<#FFAA00> [请保持安静 注意安全 谢谢配合 <3> <false>]

// 颜色也可作为独立参数
Hello <4> <#00FF00>
World <4> <#0088FF>
