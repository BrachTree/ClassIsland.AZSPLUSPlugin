# AZS.Plus For Classisland

一个为 ClassIsland 打造的增强插件集，旨在为 ClassIsland 用户提供更多实用功能与个性化体验。目前处于**早期版本**，已上线的功能仍在持续迭代中，可能存在些许问题，欢迎反馈。

> **声明：此插件由 AI 开发。**

---

## 已上线功能

### 文本轮播

从本地 txt 文件读取名言或任意文本内容，在 ClassIsland 界面上轮播显示，支持丰富的自定义选项，让你的桌面更加个性化。

#### 功能特性

- 选择本地 `.txt` 文件作为文本来源
- 支持随机或顺序轮播显示
- 支持自定义每句话或每组话的显示时长
- 支持自定义文本颜色（十六进制或颜色名）
- 支持过渡动画（淡入淡出、向上滚动、向下滚动），可按组单独禁用
- **仅独立单句**支持长文本水平滚动，可设置滚动速度和滚动完是否暂停
- 提供刷新按钮重新加载文件内容

#### 文件格式

每行为一个句子或一组句子。`//` 开头的行视为注释，会被跳过。

所有参数使用 `<参数>` 包裹，例如 `<5>` 表示显示时长5秒。

##### 单句格式

```
句子 <显示时长> <颜色> <滚动速度> <是否滚动完暂停>
```

所有参数均可省略，默认白色、使用组件设置的默认显示时长、不滚动、滚动完暂停。

示例：
```
你好世界 <5> <#FF0000>
今天天气不错 <3>
欢迎来到ClassIsland
```

##### 长文本滚动（仅限独立单句）

当独立单句文本超出容器宽度（默认 350px，可在组件设置中调整）时，自动水平滚动，**等滚动完成后才切换下一条**。短文本则按设定的显示时长正常切换。

组内句子和混合句中的组内部分**不判定长文本**，始终按显示时长切换。

```
这是一段很长的文本内容用于测试水平滚动效果 <10> <#00FF00> <50> <true>
```

- `<50>` — 滚动速度 50px/秒
- `<true>` — 滚动完暂停在末尾，等待显示时长后切换（`false` = 循环滚动，显示时长到期即切换）

##### 组格式

```
[句子1<颜色> 句子2 句子3 <每句显示时长> <是否禁用过渡动画>]
```

颜色可附着在句子后面（如 `句子1<#FF0000>`），也可省略。过渡动画参数：`true`=禁用，`false`=跟随组件设置。

组内句子**不支持**水平滚动判定。

示例：
```
[第一句<#FF0000> 第二句 第三句 <3> <true>]
[早上好 下午好 晚上好 <2> <false>]
```

##### 混合格式

单句与组的组合。根据 `[` 前是否有空格，分为两种模式：

- **紧贴模式**（`[` 前无空格，如 `前缀[组内句子...]`）：前缀固定显示，只有组内句子变化
- **独立模式**（`[` 前有空格，如 `前缀 [组内句子...]`）：前缀作为独立单句先显示，再轮播组内句子

所有参数均可省略，`<颜色>` 是可选的，不写时默认白色。前缀单句支持长文本滚动判定，组内部分不支持。

```
前缀[句子1 句子2 句子3 <每句显示时长> <是否禁用过渡动画>]
前缀 [句子1 句子2 句子3 <每句显示时长> <是否禁用过渡动画>]
```

示例：
```
ColorOS_15_[超流畅，更AI 超轻快，更自在 <7.5>]
→ 前缀「ColorOS 15」固定显示
→ 第1句: 超流畅，更AI
→ 第2句: 超轻快，更自在

温馨提示<#FFAA00> [请保持安静 注意安全 谢谢配合 <3> <false>]
→ 第1句: 温馨提示（独立显示）
→ 第2句: 请保持安静
→ 第3句: 注意安全
→ 第4句: 谢谢配合
```

##### 空格处理

组内句子以空格分隔。若句子本身需要包含空格，用下划线 `_` 连接，解析时自动替换为空格：

```
[Hello_World 你好_世界 测试成功 <3>]
```

##### 颜色格式

- 十六进制：`#RGB`、`#RRGGBB`、`#AARRGGBB`
- 颜色名：`Red`、`Blue`、`White` 等

#### 参数顺序总结

| 位置 | 单句参数 | 组参数 |
|------|----------|--------|
| 1 | 显示时长 | 每句显示时长 |
| 2 | 颜色 | 是否禁用过渡动画 |

单句额外参数（组内不适用）：

| 位置 | 单句参数 |
|------|----------|
| 3 | 滚动速度（px/秒） |
| 4 | 是否滚动完暂停 |

#### 使用方法

1. 在 ClassIsland 主界面添加「文本轮播」组件
2. 点击组件设置，选择 `.txt` 文件
3. 根据需要调整随机显示、字体大小、默认时长、过渡动画类型等参数
4. 在「长文本水平滚动」区域设置容器宽度和默认滚动速度
5. 点击「刷新」按钮可重新加载文件内容
