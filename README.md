### 文本轮播

从本地 txt 文件读取名言或任意文本内容，在 ClassIsland 界面上轮播显示，支持丰富的自定义选项（包括自定义文本颜色与渐变颜色），让你的桌面更加个性化。

#### 功能特性

- 选择本地 `.txt` 文件作为文本来源
- 支持随机或顺序轮播显示
- 支持自定义每句话或每组话的显示时长（即每句切换间隔，过渡动画时间包含在内）
- 支持自定义文本颜色（十六进制或颜色名）
- 支持自定义渐变颜色（如 `<#FF0000 #00FF00 #0000FF>` = 红绿蓝渐变，可自由指定 2 个及以上颜色），单句、前缀、后缀与组内句子均可用
- 支持过渡动画（淡入淡出、向上滚动、向下滚动、向左滚动、向右滚动），可按组单独禁用或指定动画类型
- 支持长文本水平滚动（单句用 `<long>` 标记）；组句逐句轮播并在「默认显示时长」内循环
- 提供刷新按钮重新加载文件内容

#### 文件格式

每行为一个句子或一组句子。`//` 开头的行视为注释，会被跳过。

所有参数使用 `<参数>` 包裹，例如 `<5>` 表示显示时长5秒。

##### 单句格式

```
句子 <显示时长> <颜色> <滚动速度px> <是否滚动完暂停> <long>
```

**参数通过类型自动区分：**

| 参数格式 | 含义 | 示例 |
|----------|------|------|
| `<数字>` | 显示时长（秒） | `<5>` = 5秒 |
| `<数字>px` | 滚动速度（px/秒） | `<50px>` = 50px/秒 |
| `<颜色>` | 文本颜色 | `<#FF0000>` = 红色 |
| `<渐变色>` | 文本渐变色（2 个及以上颜色） | `<#FF0000 #00FF00 #0000FF>` = 红绿蓝渐变 |
| `<true/false>` | 是否滚动完暂停 | `<true>` = 暂停 |
| `<long>` | 标记为长文本（需水平滚动） | `<long>` |

所有参数均可省略，默认白色、使用组件设置的默认显示时长、不滚动、滚动完暂停。

示例：
```
你好世界 <5> <#FF0000>
今天天气不错 <3>
这是一段长文本 <10> <50px> <true> <long>
红绿蓝渐变 <#FF0000 #00FF00 #0000FF>
```

##### 长文本滚动（仅限独立单句）

通过 `<long>` 参数显式标记长文本，标记后自动水平滚动，**等滚动完成后才切换下一条**。未标记的文本按设定的显示时长正常切换。

`<true>`（滚动完暂停）：滚动到末尾后停在末尾，并从**滚动结束的时刻**开始等待设定的显示时长，等待结束后才切换下一句。`<false>`（循环滚动）：滚动结束后短暂停顿再从头循环，**显示时长到期即切换**。

组内句子不支持水平滚动，仍按组内逐句轮播。

```
这是一段很长的文本内容用于测试水平滚动效果 <10> <#00FF00> <50px> <true> <long>
```

- `<10>` — 显示时长 10 秒（每句切换间隔）
- `<50px>` — 滚动速度 50px/秒
- `<true>` — 滚动完暂停在末尾，暂停后从滚动结束的时刻起等待显示时长再切换（`false` = 循环滚动，显示时长到期即切换）
- `<long>` — 标记为长文本，启用水平滚动

##### 组格式

```
[句子1<颜色> 句子2 句子3 <每句显示时长> <是否禁用过渡动画> <动画类型> <组渐变色>]
```

颜色/渐变色可附着在句子后面（如 `句子1<#FF0000>`、`句子2<#FF0000 #00FF00>`），也可省略。过渡动画参数：`true`=禁用，`false`=跟随组件设置。

每句的 `<每句显示时长>` 是这句的显示时长（从这句开始到切到组内下一句的间隔，包含过渡动画）。

**整组循环**：组句作为一个显示单元，若组内句子已轮播完、但整组显示时间还没到组件设置的「默认显示时长」，会回到组内第一句继续轮播；「默认显示时长」一到才切换到下一句。

**组内动画类型**（可选）：使用 `<A>` ~ `<E>` 指定组内句子的过渡动画类型：

| 参数 | 动画类型 |
|------|----------|
| `<A>` | 淡入淡出 |
| `<B>` | 向上滚动（默认） |
| `<C>` | 向下滚动 |
| `<D>` | 向左滚动 |
| `<E>` | 向右滚动 |

未指定时默认为 `<B>`（向上滚动）。单句使用组件设置中的动画类型，组内句子可独立指定。

> **注意**：组内句子**不支持水平滚动**，不解析滚动速度和暂停参数。

示例：
```
[第一句<#FF0000> 第二句 第三句 <3> <true>]
[第一句<#FF0000 #00FF00> 第二句 第三句 <3> <#FF0000 #00FF00 #0000FF>]
[早上好 下午好 晚上好 <2> <false> <A>]
```

##### 混合格式

单句与组的组合。根据 `[` 前是否有空格，分为两种模式：

- **紧贴模式**（`[` 前无空格，如 `前缀[组内句子...]`）：前缀固定显示，只有组内句子变化
- **独立模式**（`[` 前有空格，如 `前缀 [组内句子...]`）：前缀作为独立单句先显示，再轮播组内句子

所有参数均可省略，`<颜色>`/`<渐变色>` 是可选的，不写时默认白色。前缀单句支持 `<long>` 滚动，组内部分逐句轮播并整组循环。

```
前缀[句子1 句子2 句子3 <每句显示时长> <是否禁用过渡动画> <动画类型>]
前缀 [句子1 句子2 句子3 <每句显示时长> <是否禁用过渡动画> <动画类型>]
```

示例：
```
回头看见的永远是你!_[绪山真寻 02 春日野穹 玛夏 ATRI 小鸟游六花 伊蕾娜 小鸟游_星野 阿洛娜 和泉纱雾 待兼诗歌剧 宫水三叶 御坂美琴 后藤一里 阿尼亚·福杰 <0.2> <A>]
→ 前缀「回头看见的永远是你!」固定显示
→ 15 个角色名逐句轮播（每句 0.2 秒）
→ 若 15 个名字都播完、但还没到「默认显示时长」，则回到第一个名字继续轮播
→ 「默认显示时长」一到才切到下一句

温馨提示<#FFAA00> [请保持安静 注意安全 谢谢配合 <3> <false> <A>]
→ 第1句: 温馨提示（独立显示）
→ 然后组内 3 句逐句轮播，整组循环直到「默认显示时长」用完
```

##### 空格处理

组内句子以空格分隔。若句子本身需要包含空格，用下划线 `_` 连接，解析时自动替换为空格：

```
[Hello_World 你好_世界 测试成功 <3>]
```

##### 颜色格式

- 十六进制：`#RGB`、`#RRGGBB`、`#AARRGGBB`
- 颜色名：`Red`、`Blue`、`White` 等

##### 自定义渐变颜色格式

用 `#` 分隔 2 个及以上颜色即可构成渐变色（自定义渐变颜色），文本按**水平方向从左到右**依次渐变：

```
红绿蓝渐变<#FF0000 #00FF00 #0000FF>
```

- 颜色数量不限，渐变节点按顺序均匀分布：`<#FF0000 #FF8800 #FFDD00>`
- 单个颜色（如 `<#FF0000>`）仍是纯色，不会产生渐变
- 逗号、空格不能用作分隔符，分隔符只能是 `#`
- 颜色名同样可用：`<#Red #Lime #Blue>`
- 渐变色与颜色一样，既可以作为独立参数，也可以紧贴在文本末尾
- 组末尾的独立渐变色参数作为组内所有句子的默认渐变色，句子自身的颜色/渐变色优先：

```
[第一句<#FF0000 #00FF00> 第二句 第三句 <3> <#FF0000 #00FF00 #0000FF>]
```

#### 参数顺序总结

**单句参数**（按类型自动识别，顺序可互换）：

| 参数类型 | 含义 | 示例 |
|----------|------|------|
| 纯数字 | 显示时长（秒） | `<5>` |
| 数字+px | 滚动速度（px/秒） | `<50px>` |
| 颜色 | 文本颜色 | `<#FF0000>` |
| 渐变色 | 文本渐变色（2 个及以上颜色） | `<#FF0000 #00FF00 #0000FF>` |
| 布尔 | 是否滚动完暂停 | `<true>` |
| long | 标记为长文本 | `<long>` |

**组参数**（按类型自动识别，顺序可互换）：

| 参数类型 | 含义 | 示例 |
|----------|------|------|
| 纯数字 | 组内每句显示时长（秒） | `<3>` |
| 布尔 | 是否禁用组内过渡动画 | `<true>` |
| 字母A-E | 组内过渡动画类型 | `<B>` |
| 渐变色 | 组内所有句子的默认渐变色 | `<#FF0000 #00FF00 #0000FF>` |

#### 使用方法

1. 在 ClassIsland 主界面添加「文本轮播」组件
2. 点击组件设置，选择 `.txt` 文件
3. 根据需要调整随机显示、字体大小、默认时长、过渡动画类型等参数
4. 在「长文本水平滚动」区域设置容器宽度和默认滚动速度
5. 点击「刷新」按钮可重新加载文件内容

### 生日显示

从表格文档导入生日，显示**今天过生日的人数与名字**。

- 支持 `.xlsx`、`.csv`、`.txt`、`.tsv` 表格文件，自动识别表头「姓名 / 名字 / 名称」「生日 / 出生日期」
- 读取后在设置里可查看「姓名」（下拉列表）和「生日」（月日文字）
- 生日只取月、日，支持 `3月5日`、`2005-3-5`、`3/5`、`3.5`、`0305`、Excel 日期等格式
- 可设置最多显示人数，超出部分不显示，此时才显示「共 N 人」
- 可设置没有人生日时隐藏组件
- 可开启彩色渐变文字（生日主题的粉橙黄绿蓝紫渐变）

显示示例：

```
今日生日:张三 李四 王五
今日生日:张三 李四（共8人）   ← 超过最多显示人数时，只显示前几个并注明总人数
今日生日:无
```

#### 使用方法

1. 在 ClassIsland 主界面添加「生日显示」组件
2. 点击组件设置，选择生日表格文件
3. 读取后可在设置里查看「姓名」「生日」
4. 根据需要调整最多显示人数、字体大小、彩色渐变、无人生日时是否隐藏
5. 点击「刷新」可重新加载文件内容
